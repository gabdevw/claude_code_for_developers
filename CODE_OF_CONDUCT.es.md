# Código de conducta

Este es un espacio para aprender. Todas las personas son bienvenidas, sin importar su nivel de experiencia ni su idioma.

## Esperamos

- Respeto y paciencia, sobre todo con quienes empiezan.
- Comentarios sobre el trabajo, no sobre la persona.
- Suponer buenas intenciones.

## No aceptamos

- Insultos, acoso o discriminación de cualquier tipo.
- Compartir información privada de otras personas.
- Spam o promoción que no aporta nada al tema.

## Qué pasa si alguien rompe estas reglas

Las personas que mantienen el proyecto pueden editar o eliminar comentarios, issues o pull requests, y pueden bloquear a quien siga rompiendo estas reglas.

Para reportar un problema, abre un issue o contacta en privado a quienes mantienen el proyecto a través de su perfil de GitHub.
